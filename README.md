### 2. IoT Working

The basic working of an IoT system:

**Sense → Connect → Process → Act**

* **Sense:** Sensors collect data from the environment.
* **Connect:** Data is transmitted using communication technologies.
* **Process:** The collected data is processed and analyzed.
* **Act:** Based on the processed data, an action is performed.

### 3. Components of IoT

* Sensors and Devices
* Connectivity
* Data Processing
* User Interface (UI)

### 4. IoT Architecture

Studied the 4-layer IoT architecture:

**Perception → Transport/Network → Processing → Application**

* **Perception Layer:** Collects data using sensors.
* **Transport/Network Layer:** Transfers data using Wi-Fi, Bluetooth, Zigbee, Cellular networks, etc.
* **Processing Layer:** Processes and analyzes collected data.
* **Application Layer:** Provides services through applications, websites, and dashboards.

### 5. Analog and Digital Data

* Digital data is represented using discrete values such as `0` and `1`.
* Analog data is continuous and can have varying values.

**Distance = (Speed of Sound × Time) / 2**

## 🧠 Key Takeaways

* IoT connects physical objects to the Internet.
* Sensors collect information from the physical environment.
* Connectivity allows devices to exchange data.
* Data processing helps make decisions.
* Actuators perform actions based on those decisions.
* IoT can be used for automation, monitoring, safety, smart homes, agriculture, healthcare, and many other applications.

---

## 📌 Important Formulas

```text
Ohm's Law:
V = I × R

Current:
I = V / R

Resistance:
R = V / I

Speed:
Speed = Distance / Time

Distance:
Distance = Speed × Time

Ultrasonic Distance:
Distance = (Speed of Sound × Echo Time) / 2
```
